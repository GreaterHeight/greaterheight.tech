# GreaterHeight Technologies — Static Rebuild v6

This release is the template-cleaning pass. It keeps the recovered content and assets from v5 while removing captured DNN module/theme tokens, normalising the shared shell, and using one static CSS/JS layer.

## Production layer
- HTML5 documents
- `assets/css/site-v6.css`
- `assets/js/site-v6.js`
- recovered media under `assets/images`
- recovered fonts under `assets/fonts`
- no DNN/WebForms runtime
